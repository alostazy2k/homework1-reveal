4Question 4Q4 A(1)
Q4 A(1)
One-to-oneLet $f(x)=\dfrac{2x}{1+x^{2}}$ for $x\in(-1,1)$. Show that $f$ is a one-to-one function on the given domain.
  1. $\forall x_1,x_2\in(-1,1)$:$$f(x_1)=f(x_2)\;\Longrightarrow\;\frac{2x_1}{1+x_1^{2}}=\frac{2x_2}{1+x_2^{2}}$$
  2. $$2x_1\left(1+x_2^{2}\right)=2x_2\left(1+x_1^{2}\right)\;\Longrightarrow\;2x_1+2x_1x_2^{2}=2x_2+2x_2x_1^{2}$$
  3. $$2x_1+2x_1x_2^{2}-2x_2-2x_2x_1^{2}=0\;\Longrightarrow\;2x_1-2x_2+x_1x_2\left(2x_2-2x_1\right)=0$$
  4. $$2x_1-2x_2-x_1x_2\left(2x_1-2x_2\right)=0\;\Longrightarrow\;\left(2x_1-2x_2\right)\left(1-x_1x_2\right)=0$$
  5. Since $x_1,x_2\in(-1,1)$, $\;x_1x_2\neq 1$:$$2x_1=2x_2\;\Longrightarrow\;x_1=x_2$$
Answer $f$ is one-to-one.
الإجابة النهائية: $f$ is one-to-one. — عدد الضغطات: 6.

Inverse functionLet $f(x)=\dfrac{2x}{1+x^{2}}$ for $x\in(-1,1)$. Find the inverse function, $f^{-1}(x)$.
  1. Let$$y=\frac{2x}{1+x^{2}}\;\Longrightarrow\;y\left(1+x^{2}\right)=2x\;\Longrightarrow\;yx^{2}-2x+y=0$$
  2. Using the quadratic formula:$$x=\frac{2\pm\sqrt{4-4y^{2}}}{2y}=\frac{2\pm 2\sqrt{1-y^{2}}}{2y}=\frac{1\pm\sqrt{1-y^{2}}}{y}$$
  3. Since $x\in(-1,1)$:$$f^{-1}(x)=\frac{1-\sqrt{1-x^{2}}}{x}$$$$=\frac{1-\sqrt{1-x^{2}}}{x}\cdot\frac{1+\sqrt{1-x^{2}}}{1+\sqrt{1-x^{2}}}=\frac{1-\left(1-x^{2}\right)}{x\left(1+\sqrt{1-x^{2}}\right)}$$
Answer $f^{-1}(x)=\dfrac{x}{1+\sqrt{1-x^{2}}}$
الإجابة النهائية: $f^{-1}(x)=\dfrac{x}{1+\sqrt{1-x^{2}}}$ — عدد الضغطات: 5.
